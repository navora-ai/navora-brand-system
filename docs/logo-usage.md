# Logo System

## Logo Variants

NAVORA provides five logo component sets, each with contextual variants:

### 1. Master Lockup + Tagline
The primary brand signature. Use this as the default wherever space permits.
- **File**: `assets/logos/svg/master-lockup-tagline.svg`
- Contains: N-glyph + NAVORA wordmark + tagline "Clinical Intelligence Infrastructure"
- Minimum width: 200px

### 2. Wordmark
The NAVORA text mark alone.
- **File**: `assets/logos/svg/wordmark.svg` / `wordmark-navy.svg`
- Use when the glyph appears separately nearby
- Minimum width: 120px

### 3. Glyph (N-Mark)
The standalone N-monogram.
- **File**: `assets/logos/svg/glyph.svg` / `glyph-navy.svg` / `glyph-ivory.svg`
- Use for app icons, favicons, avatars, compact spaces
- Minimum size: 24×24px

### 4. Monochrome
Single-color version for special production contexts.
- **File**: `assets/logos/svg/monochrome.svg`
- Use for: single-color print, embossing, watermarks, engraving

### 5. Horizontal / Transparent
Extended horizontal layout for headers and navigation bars.
- **File**: `assets/logos/svg/horizontal-transparent.svg`
- Transparent background — works on any surface that meets contrast requirements

## App Icon

- **File**: `assets/app-icon/app-icon-1024.png` (1024×1024, 4x export)
- Deep Navy background with Ivory N-glyph
- Scale down as needed — designed to read clearly at 16×16px

## Clear Space

Minimum clear space around any logo variant = **1× the height of the N-glyph**.

No other elements, text, or imagery may intrude into the clear space zone.

## Color Application

| Background       | Logo Version        |
|------------------|---------------------|
| Ivory / Light    | Navy logo           |
| Navy / Dark      | Ivory logo          |
| Photography      | Monochrome/White    |

## Don'ts

- **Never** rotate, skew, or distort the logo
- **Never** add drop shadows, gradients, or outlines
- **Never** change the logo colors to off-brand values
- **Never** rearrange the lockup components
- **Never** place the logo on a busy background without sufficient contrast
- **Never** scale below minimum sizes
- **Never** animate the logo
