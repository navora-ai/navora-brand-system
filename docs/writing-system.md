# Writing System

## Voice Principles

NAVORA speaks as a **clinical colleague** — knowledgeable, precise, and respectful.

| Principle           | Do                                          | Don't                                      |
|---------------------|---------------------------------------------|--------------------------------------------|  
| Professional        | "Review the updated lab results"            | "Check out your new labs!"                 |
| Precise             | "Hemoglobin: 12.8 g/dL (ref: 12.0–16.0)"  | "Your hemoglobin is normal"               |
| Confident           | "Evidence supports this recommendation"     | "This is the best recommendation ever"     |
| Structured          | Bullet points with clear hierarchy          | Long unbroken paragraphs                   |
| Empathetic          | "We understand this may raise questions"    | "Don't worry about it"                     |

## Tone by Product

### Patient
- Warm, clear, reassuring
- Plain language (8th-grade reading level)
- Explain medical terms on first use

### Provider
- Precise, efficient, data-forward
- Clinical terminology expected
- Lead with data, follow with context

### Nexus
- Structured, cross-referencing, coordination-focused
- Task-oriented language
- Always specify the source

## Capitalization

| Element            | Style               | Example                    |
|--------------------|----------------------|----------------------------|
| Page titles        | Title Case           | Patient Overview           |
| Section headers    | Title Case           | Recent Lab Results         |
| Button labels      | Title Case           | Save Changes               |
| Body text          | Sentence case        | Your next appointment is…  |
| Status labels      | Title Case           | Action Required            |
| Error messages     | Sentence case        | Please enter a valid date  |

## Punctuation

- No periods on button labels, headings, or labels
- Periods on full sentences
- No exclamation marks in UI text — ever
- Oxford comma in lists
- Em dash (—) for parenthetical statements

## Numbers & Data

| Type              | Format                    | Example              |
|-------------------|---------------------------|----------------------|
| Dates             | DD MMM YYYY               | 08 Sep 2026          |
| Times             | HH:MM (24h) or H:MM AM/PM| 14:30 or 2:30 PM     |
| Clinical values   | Value + unit + reference  | 12.8 g/dL (12.0–16.0)|
| Percentages       | Numeral + %               | 85%                  |

## Error Messages

Structure: **What happened** + **Why** + **What to do**

## Terminology

| Use                  | Don't Use              |
|----------------------|------------------------|
| Sign in / Sign out   | Log in / Log out       |
| Patient              | Client, User, Customer |
| Provider             | Doctor (unless specific)|
| Evidence             | Proof, Citation        |
| Verified             | Approved, Confirmed    |
| Safety alert         | Warning, Danger        |
